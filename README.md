# Controle-de-Investimentos-DIO-
/Projeto de Controle de Investimentos feito em curso de analise de dados com excel da plataforma DIO
Criamos uma planilha para controle de investimentos de FIIS, com possibilidade de acompanhar os rendimentos de acordo com o valores variados 
a serem aportados mensalmente, para que possamos ter uma perspectivas de lucro ao longo dos anos
Criamos tabelas, usamos formulas como PROCV e VF para valores Futuros, assim conseguimos ver rapidamente o planejamento conforme valor a ser
aportado mensalmente, e propondo valores de acordo com salário da pessoa
